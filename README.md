# 基于轻量化深度学习的智能心音辅助检测系统

> 本科生科研训练与教学型系统开发项目

心音正常/异常**二分类**，配一套可在普通个人计算机上**离线运行**的教学型可视化系统。

---

## ⚠️ 使用边界（先看这一条）

**本系统仅用于教学、科普和算法验证，不用于医学诊断或临床决策。**

- 不根据正常/异常二分类结果推断具体疾病
- 不向用户提供治疗建议
- 不展示未经算法验证的生理指标（如心率、S1/S2 强度、杂音频率）
- 所有报告和界面必须显著注明非医疗用途

这条边界适用于项目的**每一个阶段**，包括课堂演示和答辩。

## 目录结构

```
.
├── configs/            # 实验配置与模型参数（每次正式实验留一份）
├── data_manifest/      # 元数据、数据划分清单和排除日志
├── src/                # 全部源码
│   ├── preprocessing/  # 重采样、滤波、切片和频谱生成
│   ├── features/       # 传统特征提取
│   ├── models/         # 传统模型与深度模型
│   ├── training/       # 训练、验证和日志
│   ├── inference/      # 片段预测与录音级聚合
│   └── evaluation/     # 指标、置信区间和鲁棒性实验
├── app/                # 前端与系统接口
├── tests/              # 单元测试和系统一致性测试
├── checkpoints/        # 冻结模型与标签映射（权重文件不上传）
├── reports/            # 实验报告、图表和错误案例
├── docs/               # 使用说明、接口文档和教学材料
│   └── archive/        # 旧方案文档归档（只读）
├── environment/        # 软件依赖与运行环境
└── data/               # 原始数据集（不上传 Git）
```

> 源码**不要**平铺在根目录。新建文件请放到对应目录。

## 核心纪律（违反则实验作废）

1. **先划分，后处理** —— 先按受试者分成训练/验证/测试，之后才切片和提特征。顺序不能反。
2. **测试集封存** —— 冻结之前，任何人不得依据测试结果调参。测试集清单由刘文鑫保存，最终测试由郝静组织。
3. **以录音级评价为主** —— 片段只是模型的输入单元，主要指标按整条录音计算。
4. **训练集独立变换** —— 标准化参数、类别平衡、数据增强只能从训练集拟合。
5. **基线先行** —— 先跑通传统模型，再判断复杂结构是否真有改进。
6. **轻量化必须量化** —— 报出参数量、模型大小、CPU 推理时间和内存占用。
7. **输出不超过算法证据** —— 模型只做二分类，界面和报告就只能说二分类的结果。

## 常见问题

**Q：我能直接把代码传到根目录吗？**
不能。请按上面的目录结构放到对应位置。

**Q：原始数据集要传上去吗？**
不要。`data/` 已被 `.gitignore` 忽略。仓库里只保存**数据清单、文件哈希和数据来源说明**，不打包原始数据。

**Q：模型权重呢？**
也不传。`*.pth`、`*.h5`、`*.pkl` 已被忽略。冻结模型放 `checkpoints/`，但权重文件本身不入库。

**Q：`git add .` 安全吗？**
安全。`.gitignore` 已经覆盖虚拟环境、数据集、模型权重、Word 临时文件等。提交前建议用 `git status` 再确认一眼。
