摘要
针对原方案中数据划分口径不统一、潜在数据泄漏、固定切片依据不足、类别
平衡时机不明确、片段级与录音级评价混淆、轻量化缺乏量化证据以及界面指标与
算法能力不匹配等问题，本文提出一套从实验设计开始重构的完整方案。新方案以
“受试者隔离、测试集封存、训练阶段独立变换、录音级评价、基线先行、轻量模型
逐步升级、系统输出有证据约束” 为基本原则，将项目划分为需求冻结、数据审计、
数据划分、信号预处理、基线建模、轻量深度模型、训练与调参、独立测试、鲁棒性
评价、模型解释、系统集成和项目验收十二个阶段。每个阶段均明确操作方法、设
置理由、输出物及验收条件，使最终结果可复现、可比较、可解释，并适合教学演
示与普通个人计算机离线运行。
关键词：心音分类；轻量化深度学习；梅尔频谱；受试者级划分；数据泄漏；鲁
棒性评价；教学演示系统

1
项目重新定位
1.1
项目目标
本项目重新定位为一套面向教学、科普与算法实验的心音辅助分析系统。系统输入
为不含个人身份信息的心音录音，输出正常/异常二分类结果、置信度、波形与时频特
征展示，以及对模型处理流程和结果局限性的说明。系统不得将分类结果表述为疾病诊
断，也不得根据二分类结果自动推断具体疾病。
重构后的目标分为三个层次：
1. 实验目标：建立无明显数据泄漏、可复现、评价口径统一的心音分类实验流程；
2. 算法目标：在传统机器学习基线之上训练轻量深度模型，并在准确性、模型大小和
推理速度之间取得平衡；
3. 系统目标：实现录音上传、合法性检查、预处理、模型推理、结果展示、历史记录
和报告导出，形成可在普通PC 端离线运行的教学原型。
1.2
旧成果的保留与废止
推倒重做不等于删除全部已有工作。应按“是否会污染实验结论” 判断旧成果能否
复用。

重构的核心原则
1. 先划分，后处理。必须先按受试者或原始录音划分训练集、验证集和测试集，再进
行切片、特征提取、平衡和增强。
2. 测试集封存。测试集不得参与归一化参数估计、阈值选择、模型选择和超参数搜索，
只在最终方案冻结后使用一次。
3. 以录音级评价为主。切片只是模型输入单元，最终系统处理的是完整录音，因此主
要性能指标必须在录音级计算。
4. 训练集独立变换。过采样、欠采样、数据增强和特征标准化参数拟合仅发生在训练
集。
5. 基线先行。先建立可解释且可复现的传统模型和简单CNN，再判断复杂结构是否
带来真实改进。
6. 轻量化必须量化。除分类指标外，必须同时报告参数量、模型大小、CPU 推理时

7. 输出能力不超过算法证据。模型只完成正常/异常二分类时，界面和报告不得给出

3
完整项目流程总览
重构项目按照以下顺序实施：
需求冻结→数据审计→受试者级划分→预处理与切片→传统基线→轻量深度模型
→训练与调参→独立测试→鲁棒性实验→可解释性分析→系统集成→验收归档。
该顺序不可任意调换。例如，如果先生成片段再随机划分，即使后续模型结构设计
得很好，评价结果仍可能因同源片段泄漏而失去可信度。
4
第一阶段：需求冻结与实验协议登记
4.1
具体工作
在重新编写模型代码前，先形成一份不可随意更改的实验协议，至少确定：
• 主任务为正常/异常二分类；
• 数据集版本、纳入与排除标准；
• 划分单位是受试者；若缺少可靠受试者编号，则退而采用原始录音；
• 主评价指标、辅助指标和轻量化指标；
• 测试集封存方式；
• 允许使用的模型、增强方法与超参数搜索范围；
• 系统仅用于教学与科普，不作医学诊断。
设置理由：先冻结实验协议可以避免研究者看到测试结果后反复改变切片长度、阈值、
数据范围或指标，从而产生对测试集的隐性过拟合。
阶段输出：《实验协议表》、固定随机种子列表、数据与代码版本编号。
验收条件：项目成员能够依据同一协议独立回答“训练集、验证集和测试集分别用于什
么”，且答案完全一致。

第二阶段：数据审计与清单建立
5.1
数据来源与使用范围
以公开心音数据为主要来源。首轮重构建议先固定一个主数据集完成闭环，例如使
用2016 PhysioNet/CinC 心音挑战数据；其他公开数据集用于外部验证或后续扩展，不
应在首轮实验中无说明地混合。
5.2
建立录音级元数据表
每条原始录音对应元数据表中的一行，建议包含：
录音ID、受试者ID、数据子库、标签、原始采样率、时长、通道数、文件哈希、质量
状态、排除原因。
对数据执行以下审计：
1. 检查文件能否正常读取、是否为空、是否损坏；
2. 检查标签是否合法并统一编码；
3. 使用文件哈希和波形相似度检查完全重复或近重复录音；
4. 统计各类别、各子库和各受试者的数量与时长分布；
5. 标记过短、削波严重、近乎静音或噪声极强的录音；
6. 保留排除日志，不直接静默删除数据。
设置理由：模型性能不仅由网络决定，也由数据质量、标签可靠性和设备分布决定。先
建立可追踪清单，才能定位异常结果来自模型还是来自数据。文件哈希还能防止重复录
音跨集合出现。
阶段输出：录音级元数据CSV、重复样本报告、排除样本清单、类别与数据源统计图。
验收条件：任意一个训练片段都可以追溯到唯一原始录音、受试者和数据子库；所有排
除项均有明确原因。

第四阶段：统一的信号预处理与切片
7.1
基础预处理
建议采用以下确定性流程：
1. 将多通道音频统一转为单通道；
2. 重采样到统一采样率。首轮可选2000 Hz 或4000 Hz，并通过消融实验确定；
3. 去除直流分量；
4. 采用适合心音主要频段的带通滤波，同时保留未滤波版本用于对照；
5. 对每条录音进行稳健幅值归一化，并加入极小量ε 防止除零；
6. 记录处理前后的波形，不在测试阶段使用训练标签参与处理。

窗口设计
不再把0.5 秒直接解释为完整心动周期。首轮建议以2 秒窗口、1 秒步长作为主方
案，同时把1 秒窗口作为消融对照。对不足一个窗口的尾段采用零填充并记录有效长度，
避免训练和推理采用不同规则。
如果后续心音分割算法足够稳定，可增加“按S1 到下一次S1 截取完整心动周期”
的方案，但不应在首轮同时引入过多不稳定模块。

第五阶段：建立传统机器学习基线
先提取一组可解释的录音级或片段级特征，例如MFCC 及其一阶、二阶差分统计
量、谱质心、谱带宽、谱滚降、过零率和短时能量，再训练逻辑回归、支持向量机或梯
度提升树。
特征标准化器、特征选择器和分类器必须组成同一训练管线，并在每个训练折内拟
合，不能先对全体数据标准化后再交叉验证。
设置理由：传统基线能够回答“深度模型是否确实优于简单方法”。如果复杂模型没有显
著超过基线，就应优先检查数据、标签和训练流程，而不是继续堆叠网络。传统模型还
便于教学中解释特征与分类之间的关系。
阶段输出：基线特征表、训练管线、分组交叉验证结果、独立验证集结果。
验收条件：基线训练可以由固定配置一键复现；所有变换仅在训练折拟合；结果包含均
值和标准差。

9.2
对比模型与升级顺序
模型升级应一次只增加一个关键模块：
1. 普通轻量CNN；
2. CNN 加残差连接；
3. CNN 加通道注意力；
4. 1D-CNN 直接处理波形；
5. 仅在前述结果显示必要时，再考虑CRNN 或更复杂结构。
每次升级必须通过相同数据划分和训练预算进行消融比较。若新增模块没有稳定改
善主指标，便不进入最终模型。
设置理由：同时改变网络深度、输入特征、增强策略和损失函数，无法判断性能变化来
自哪里。逐项消融能够把改进与具体设计对应起来，避免为了结构复杂而复杂。
阶段输出：模型结构配置、参数量、计算量、模型文件大小和网络结构图。
验收条件：每个候选模型都能由配置文件重建；最终模型的轻量化指标优于旧模型或预
先设定的资源上限。

第七阶段：训练、增强与超参数选择
10.1
训练策略
采用AdamW 或Adam 优化器，设置学习率衰减、早停和最佳权重保存。早停依据
验证集损失或预先指定的主指标，不能依据测试集表现。保存随机种子、软件版本、训
练日志和最佳轮次。
10.2
训练集数据增强
增强只作用于训练集，可逐项考察：
• 小幅随机增益；
• 时间平移；
• 与真实场景幅度相符的背景噪声叠加；
• 小范围时间拉伸；
• 梅尔频谱的时间掩蔽和频率掩蔽。
禁止使用缺乏声学意义的垂直翻转、大角度旋转等普通图像增强。
设置理由：增强的目标是模拟可能出现而不改变标签的录音变化。只对训练集增强可避
免增强副本进入验证集或测试集；采用具有声学意义的变换可以减少标签被破坏的风
险。
10.3
超参数搜索
搜索范围应提前限定，包括学习率、批量大小、卷积通道数、Dropout、窗口长度和
聚合方法。可采用小规模随机搜索或贝叶斯优化，但所有候选模型使用相同训练预算。
最终只根据验证集或训练集内部交叉验证选择模型。
设置理由：无边界地反复试验容易对验证集过拟合，也不利于复现。提前限定搜索空间
和预算能够保证模型比较公平。
阶段输出：训练日志、学习曲线、超参数搜索表、最佳模型权重和完整配置。
验收条件：重复运行可得到接近的结果；训练曲线不存在明显的实现错误；模型选择过
程从未读取测试标签。

比较的公平性
传统模型、CNN 和升级模型必须使用相同的训练、验证和测试对象。不得为不同

第十阶段：鲁棒性、泛化性与消融实验
13.1
鲁棒性实验
在不重新训练的前提下，对测试录音构造不同信噪比的噪声版本、轻微增益变化和
采样设备差异模拟，观察性能随干扰强度的变化。噪声参数必须预先设定，不应根据结
果挑选。
13.2
跨数据源泛化
若数据条件允许，使用未参与训练的另一公开数据子库或数据集进行外部测试。应
把“同分布测试” 和“跨数据源测试” 分开报告，不能混为同一个准确率。
13.3
消融实验
建议至少比较：
1. 无滤波与带通滤波；
2. 1 秒与2 秒窗口；
3. 无增强与有增强；
4. Flatten 与全局平均池化；
5. 普通卷积与深度可分离卷积；
6. 均值、最大值和Top-q 聚合。
设置理由：同分布测试只能说明模型对相似数据有效，不能说明对设备变化和背景噪声
稳定。鲁棒性与外部验证能够暴露模型是否学习了数据源特征；消融实验则说明每项设
计是否真正有用。
阶段输出：噪声强度–性能曲线、跨数据源结果表和消融实验表。
验收条件：所有对比只改变一个因素，并保持数据划分、训练预算和评价方法一致。

结论
本次重构的重点不应是立即寻找更复杂的神经网络，而应先重建可信的数据与评价
链路。项目应首先完成数据审计和受试者级划分，随后统一预处理、建立传统基线和轻
量CNN，再通过录音级聚合、独立测试、鲁棒性实验和效率评价确定最终模型。系统端
必须调用与实验端完全相同的预处理和推理代码，并把输出限制在算法能够证明的范围
内。
完成上述流程后，即使最终准确率没有出现不合理的高值，所得结论也会比原方案
更可靠。对本科生创新项目而言，能够清楚证明无数据泄漏、实验可复现、模型真正轻
量、系统输出边界明确，本身就是比单纯追求一个高准确率更有价值的成果。
